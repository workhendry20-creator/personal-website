## Overview

USM PhysX Lab is an interactive web-based physics simulation engine developed for mathematical physics experiments during the international research internship at Universiti Sains Malaysia.

## Features

- **Interactive Physical Models:** Real-time simulation of differential equations, pendulum dynamics, and wave propagation.
- **Mathematical Numerical Solver:** Integrated numerical algorithms in JavaScript and Python to compute physics trajectories.
- **User-Friendly Dashboard:** Responsive user interface styled with Tailwind CSS for seamless parameter adjustments.

## Technology Stack

- **Frontend & Logic:** JavaScript (ES6+), HTML5 Canvas
- **Computational Modeling:** Python (NumPy, SciPy)
- **Styling:** Tailwind CSS
