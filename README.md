# Personal Digital Space & Thought Garden

Personal space & editorial portfolio by **Hendry Bambang Siswanto**. Focuses on narrative writing, thoughts, and multidisciplinary projects across Information Systems, Physics, Youth Diplomacy, and Technopreneurship.

## 🚀 Tech Stack

- **Framework:** [Next.js 14+](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling:** [Tailwind CSS v3.4+](https://tailwindcss.com/)
- **Content:** MDX files stored in local `content/` directory

## 📁 Directory Structure

```text
├── app/                  # Next.js App Router (pages, layouts, globals.css)
├── content/              # Local MDX content files
│   ├── notes/            # Digital garden notes & thoughts
│   └── projects/         # Curated project case studies
├── public/               # Static assets (images, favicon)
├── tsconfig.json         # TypeScript strict configuration with `@/*` path alias
├── tailwind.config.ts    # Tailwind CSS configuration
├── PRD.md                # Product Requirement Document & Roadmap
└── README.md             # Project documentation
```

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

To build for production:

```bash
npm run build
```
